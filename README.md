# Кодекс Висконсина

Официальный законодательный портал штата Висконсин, город Гринвиль.

## О проекте

Этот проект содержит полные тексты кодексов штата Висконсин:

- **Дорожный кодекс** — правила дорожного движения
- **Уголовный кодекс** — уголовные преступления и наказания
- **Административный кодекс** — административные правонарушения
- **Налоговый кодекс** — налоговое законодательство

## Использование

Просто откройте `index.html` в браузере или посетите наш [официальный портал](https://ваш-логин.github.io/wisconsin-code/).
